# 📊 Sales & Orders Analysis Dashboard

## 📌 Project Overview

This project analyzes sales and order data using **MySQL and Power BI** to identify sales patterns, category performance, order trends, and top-performing products.

The project combines SQL-based data analysis with an interactive Power BI dashboard to present business insights in a clear and visual format.

## 🎯 Project Objectives

* Analyze sales and order data using SQL
* Identify sales performance by product category
* Analyze order distribution across categories
* Identify top-performing products
* Analyze sales trends over time
* Build an interactive Power BI dashboard

## 🛠️ Tools & Technologies

* **MySQL**
* **SQL**
* **Power BI**
* Data Modeling
* Data Visualization

## 🔍 SQL Analysis

SQL was used to perform:

* Table joins
* Aggregations
* `GROUP BY` analysis
* Order and sales calculations
* Category-level analysis
* Product-level analysis
* Business-oriented data analysis

## 📈 Power BI Dashboard

The dashboard includes:

* **Total Orders**
* **Total Sales**
* **Orders by Category**
* **Sales by Category**
* **Sales Trend Over Time**
* **Top Products by Sales**
* **Category Slicer** for interactive filtering
